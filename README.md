# Systems Programming Laboratory

This repository serves as a personal log of my journey through systems programming, open-source contributions, and low-level experimentation.

The goal of this lab is to document my progress, solidify my understanding of core concepts, and build a reference library of code snippets and implementations.

## Repository Structure

- **`/c`**: Low-level programming, manual memory management, and fundamental data structures.
- **`/rust`**: Safe and concurrent implementations leveraging the borrow checker.
- **`/linux`**: Bash scripting, system calls, and Linux kernel exploration.
- **`/virtualization`**: Labs on containers, hypervisors, and resource isolation.
